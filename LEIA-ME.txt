MARISA DEPILAÇÃO — como subir no GitHub
=======================================

Arquivos (suba TODOS, soltos, sem pasta):
  index.html          -> o app
  manifest.json       -> permite instalar como aplicativo
  sw.js               -> faz o app abrir sem internet e receber atualizações
  papel-de-parede.png -> papel de parede (aparece em Mais > Meu estúdio)
  icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
                      -> ícones do app (Android e iPhone)

Passo a passo:
  1. Crie um repositório (ex.: marisa-depilacao).
  2. Add file > Upload files > selecione os 9 arquivos de uma vez.
  3. Commit changes.
  4. Settings > Pages > Branch: main / (root) > Save.
  5. Abra o link https://SEU-USUARIO.github.io/marisa-depilacao/ no celular.
  6. No app, toque em "Instalar".

Para atualizar depois (o Claude já faz isso a cada mudança):
  - No index.html, na linha:
      const APP_BUILD='34', APP_VERSAO_TXT='1.4', APP_DATA='30/09/2026'; // APP_VERSAO='34' ...
    * APP_BUILD: número interno, sempre +1 (34 -> 35). O app usa ele para saber se tem versão nova.
    * APP_VERSAO_TXT: a versão que aparece para a Marisa (1.4 -> 1.5 -> 1.6...).
    * APP_DATA: data do dia.
    * No comentário do fim, APP_VERSAO='34' ...mpanha o APP_BUILD (serve para celulares com versão antiga).
  - No sw.js, a versão acompanha o APP_BUILD:  marisa-v34 -> marisa-v35
